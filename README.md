# Computer Systems: A Programmer's Perspective（CSAPP）

《深入理解计算机系统》(*Computer Systems: A Programmer's Perspective*) 中文版学习资料存档。

本仓库收录个人学习期间扫描的教材页面（含手写批注），按书中章节组织。

## 目录结构

```
扫描件/
    目录/                       全书目录
    第2章 信息的表示和处理/       2.1 信息存储 / 2.2 整数表示 各小节扫描页
    第8章 异常控制流/             8.1 异常 ~ 8.5 信号 各小节扫描页
```

文件命名规则：`<小节号 小节标题>-<序号>.pdf|jpg`，例如 `8.4.6 利用 fork 和 execve 运行程序-1.pdf`。

| 第 8 章 异常控制流 | 8.1 异常、8.2 进程、8.3 系统调用错误处理、8.4 进程控制、8.5 信号 | 58 |
